# Gyro Blitz

A browser game. Catch falling gyro ingredients, dodge the lightning bolts, don't die.

Built with React + Vite, rendered on a canvas. Scores persist in localStorage.

## How to play

- **← →** arrow keys or just move your mouse
- Catch 🥙🧅🍅🥒🫓🧀🫒 for +10 points each
- Dodge ⚡ — three hits and you're out
- Gets faster as your score climbs

## Run it

```bash
npm install
npm run dev
```
